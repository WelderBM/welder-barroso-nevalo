## Sobre o Projeto

Este é o **site pessoal e portfólio** de Welder Barroso de Melo — desenvolvedor frontend baseado em Roraima, Brasil. Mais do que um portfólio, é a **vitrine da marca Nevalo**: uma empresa de software humana, que enxerga cada projeto como uma ponte entre pessoas e tecnologia.

O site foi construído sem frameworks — **HTML semântico, CSS3 e JavaScript puro** —, com design sistema próprio derivado do Nevalo Design System. A identidade visual é intencional: tons profundos de marinha, acento teal (#1BE4C8) e tipografia Bebas Neue + Lora criam uma atmosfera única entre o técnico e o humano.

**Diferenciais técnicos da interface:**
- Cursor customizado com efeito de seguimento fluido (JavaScript puro)
- Canvas animado com partículas e linhas de conexão no fundo
- Animações de scroll com IntersectionObserver
- Layout totalmente responsivo sem framework CSS

## About

This is the **personal portfolio** of Welder Barroso de Melo — a frontend developer based in Roraima, Brazil. More than a portfolio, it's the **showcase of the Nevalo brand**: a human software company that sees each project as a bridge between people and technology.

The site was built without frameworks — **semantic HTML, CSS3, and Vanilla JavaScript** — using a proprietary design system derived from the Nevalo Design System. The visual identity is intentional: deep navy tones, teal accent (#1BE4C8), and Bebas Neue + Lora typography create a unique atmosphere between the technical and the human.

**Technical interface highlights:**
- Custom cursor with fluid follow effect (Vanilla JS)
- Animated canvas with particles and connection lines in the background
- Scroll animations with IntersectionObserver
- Fully responsive layout without a CSS framework

| **Experience** | Full professional timeline (Pigz, R2T, Code Club) |
